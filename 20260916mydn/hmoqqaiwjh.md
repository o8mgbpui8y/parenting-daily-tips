# 柳州市工人医院顺利通过产前诊断技术校验现场评审

> 更新时间：2026-09-16 (UTC+8)

2024年12月19上午，自治区产前诊断技术评审专家组一行6人对我院进行三年一周期的执业校验现场评审。

评审专家组由广西壮族自治区妇幼保健院丘小霞教授、蒙达华教授、黎新艳教授，广西壮族自治区人民医院李友琼教授，广西壮族自治区卫健委妇幼健康处陈碧艳教授，广西壮族自治区卫生监督所王莆超教授组成。

评审会现场

柳州市工人医院院长黄海欣、副院长侯培勇、原纪委书记邱萍、医务科副主任叶珊珊、伦理办公室主任涂晓宁、妇产科主任方梓羽、优生遗传室主任蒙俊、产科主任胡敏、超声科主任郭丽萍、超声科副主任计柳玉、医学检验科副主任蒙杰及相关科室人员参加了评审汇报会。会议由侯培勇副院长主持，首先黄海欣院长对各位评审专家的到来表示热烈欢迎及衷心感谢，其次由蒙俊主任对我院本周期产前诊断工作进行详细汇报。

柳州市工人医院院长黄海欣介绍医院基本情况

柳州市工人医院副院长侯培勇主持评审会

广西壮族自治区妇幼保健院丘小霞教授介绍评审标准

柳州市工人医院优生遗传室主任蒙俊对本周期产前诊断工作进行详细汇报

随后，专家组根据《广西壮族自治区产前诊断技术服务机构校验评审标准（2021修订）》要求，分专业组通过实地检查、查阅资料和现场提问等形式，对我院产前诊断技术组织管理、质量控制、临床技术、超声技术、实验室技术以及伦理管理等方面进行了全面、严谨、细致地评审。

各专家组实地评审

通过一上午紧密的考评，专家组对我院产前诊断工作给予了高度评价，充分肯定了医院领导对产前诊断技术发展的重视，对我院规范开展产前诊断工作及取得的亮点给予赞扬。最后，丘小霞教授代表评审专家组宣布，我院通过产前诊断机构校验现场评审，同时也对一些不足之处提出了改进意见。

各评审组专家提出改进意见

侯培勇副院长对评审专家组的现场评审以及提出的建议表达了衷心感谢，同时表示我院将以本次评审为契机，持续提高相关专业组产前诊断技术能力，争取把我院产前诊断技术服务体系建设推向一个新的高度。同时要求产前诊断技术团队以评促改，以评促建，进一步提高专业技术水平，为降低出生缺陷、提高出生人口素质做出更大的贡献。

侯培勇副院长对评审组专家的工作表示感谢

柳州市工人医院自2015年12月获得产前诊断资质以来，顺利通过了2次校验评审，一直认真贯彻落实《母婴保健法》《产前诊断技术管理办法》等相关规定，依法开展产前诊断工作，持续提高服务质量，组织机构健全，人员培训制度化，知识更新常态化；促进各科室认真落实各项制度，不断规范母婴保健和产前诊断技术服务管理，加强院内外的宣传工作，提高服务质量，为保障群众生殖健康、提高出生人口素质保驾护航。
